## O que é uma Variável?

As Variáveis são componentes usados para armazenar informações que podem ser lidas, comparadas e alteradas por outros Wireds. Elas funcionam como dados do sistema wired, guardando valores que nos ajudam a tomar decisões e responder de formas diferentes em cada situação.

Elas permitem criar mecânicas mais avançadas, como sistemas de pontos, vidas, progresso, contadores, estados de mobis, informações de usuários e dados compartilhados no quarto. Dependendo do tipo, uma variável pode pertencer a um usuário, a um mobi, ao quarto inteiro ou até à execução atual de uma pilha Wired.

Elas não precisam ficar empilhadas na pilha principal para funcionar. O papel delas é servir como base de informação para o sistema wired, permitindo que outros Wireds consultem, filtrem, transformem e reutilizem valores ao longo do sistema.
