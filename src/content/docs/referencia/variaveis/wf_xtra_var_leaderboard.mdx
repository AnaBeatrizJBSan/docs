O **Extra Variável: Placar** permite mostrar os registros de uma variável permanente de usuário em uma janela no quarto. Quer exibir a pontuação dos jogadores, acompanhar seus níveis ou mostrar quem teve o progresso atualizado mais recentemente? Você pode escolher quais informações aparecem no placar e como elas serão organizadas.

<Infobox />

## Requisitos

Coloque este Extra acima de um [Wired Variável: Usuário Variável](/referencia/variaveis/wf_var_user/) configurado com disponibilidade **permanente**. O placar utiliza os registros associados a essa variável.

Por exemplo, você pode criar uma variável de usuário chamada `pontuacao`, configurá-la como **Permanente** e utilizá-la para guardar os pontos de cada jogador. O Extra permite apresentar esses dados para quem está no quarto.

<Aside type="caution" title="Confira a variável da pilha">
Se a pilha não tiver uma variável permanente de usuário, a seção **Geral** mostrará um aviso em vermelho informando que o placar ficará vazio. Confira a posição do Extra e a [disponibilidade da variável](/referencia/variaveis/wf_var_user/#opções-de-disponibilidade) antes de continuar.
</Aside>

## Como esse Wired funciona?

Ao clicar duas vezes no Wired, duas janelas são abertas: a de **configuração** e a do **placar**. Na configuração, você escolhe o título, a ordenação, as colunas, os filtros e a localização do placar.

Depois de salvar as configurações, a janela do placar aparecerá para todos os usuários no quarto.

![Janela de configuração do Extra Variável Placar ao lado do placar vazio, com as colunas Username e Value.](@assets/wf_xtra_var_leaderboard/01-janelas-do-wired.png)

### Geral

Comece definindo como o placar será apresentado:

* **Título:** o nome que aparece no topo da janela do placar. Aceita até **50 caracteres**.
* **Descrição:** um texto que aparece abaixo do título e pode explicar o que está sendo mostrado. Aceita até **80 caracteres**.

Por exemplo, um placar de uma competição pode ter o título **Pontuação dos jogadores** e a descrição **Confira os pontos conquistados nos desafios do quarto**.

![Campos Título e Descrição preenchidos com Wired Club - Pontuação e Pontos conquistados no Wired Club, exibidos no topo do placar.](@assets/wf_xtra_var_leaderboard/02-topico-geral.png)

#### Ordenação

Escolha qual informação será utilizada para organizar os registros:

| Opção | Como organiza os registros |
| :--- | :--- |
| **Maior valor** | Mostra primeiro os maiores valores da variável. |
| **Menor valor** | Mostra primeiro os menores valores da variável. |
| **Data de criação mais antiga** | Mostra primeiro os registros criados há mais tempo. |
| **Data de criação mais recente** | Mostra primeiro os registros criados mais recentemente. |
| **Data de modificação mais antiga** | Mostra primeiro os registros cuja última alteração ocorreu há mais tempo. |
| **Data de modificação mais recente** | Mostra primeiro os registros alterados mais recentemente. |

Para um placar de pontos, por exemplo, escolha **Maior valor** para colocar os jogadores com mais pontos no início da lista.

#### Tamanho da página

Você pode selecionar **10**, **15** ou **20** registros por página. Ajuste essa opção conforme a quantidade de informações que deseja mostrar de uma vez.

### Colunas

O campo **Número de colunas** permite escolher de **1 a 4** colunas. Inicialmente, elas são organizadas assim:

| Quantidade | Colunas exibidas |
| :--- | :--- |
| **1** | Nome de usuário |
| **2** | Nome de usuário e Valor |
| **3** | Nome de usuário, Valor e Texto |
| **4** | Nome de usuário, Valor, Texto e Última atualização |

Abaixo desse campo, você encontra as opções para configurar cada coluna.

#### Nome e largura das colunas

A primeira coluna sempre mostra o **nome de usuário** e não pode ser substituída por outro tipo. Por padrão, seu título é **Username**, mas você pode alterá-lo para um nome como **Jogador**. O novo título deve ter pelo menos **2 caracteres**.

Você também pode ajustar a largura das colunas, escolhendo entre **Pequeno**, **Médio**, **Grande** e **Extra grande**. Isso ajuda a distribuir o espaço conforme o conteúdo que será exibido.

<img src={NomeELarguraDasColunas.src} alt="Demonstração da configuração das colunas e do ajuste de sua largura na janela do placar." style={{ width: "480px", maxWidth: "100%", height: "auto" }} />

#### Tipos de coluna

As demais colunas podem ser configuradas com um dos seguintes tipos:

| Tipo | O que mostra |
| :--- | :--- |
| **Valor** | O valor da variável associado ao usuário. |
| **Texto*** | O texto associado ao valor da variável pelo Extra Variável: Conector de Texto. |
| **Última atualização** | Há quanto tempo o registro foi atualizado, como **há 2 min**. |
| **Data de criação** | Há quanto tempo o registro foi criado, como **há 15 min**. |
| **Nível*** | O nível atual do jogador, calculado pelo Extra Variável: Sistema de Aumento de Nível. |

Não é necessário escolher um tipo diferente para cada coluna. Você pode, por exemplo, manter **Nome de usuário** na primeira e utilizar **Última atualização** nas outras três.

<Aside type="note" title="Colunas que precisam de outros Extras">
O asterisco em **Texto** e **Nível** indica que essas colunas dependem de outro Extra de Variável na pilha. Para mostrar textos, utilize o [Conector de Texto](/referencia/variaveis/wf_xtra_var_text_connector/). Para mostrar níveis, utilize o [Sistema de Aumento de Nível](/referencia/variaveis/wf_xtra_var_lvlup_system/).
</Aside>

### Modo de múltiplas variáveis

Quer utilizar o mesmo placar para consultar mais de uma variável? Coloque vários Wireds de variável permanente de usuário na mesma pilha do **Extra Variável: Placar**. Assim, os usuários poderão escolher qual variável consultar na janela do placar.

Nesta seção, cada variável da pilha aparece ao lado de um campo de texto. Preencha esse campo com o nome que deseja mostrar no placar. Isso permite apresentar um nome mais fácil de ler sem alterar o nome definido no Wired de variável.

O botão **Sugerir nomes** preenche esses campos com nomes baseados nas variáveis. Por exemplo, `placar_um` recebe a sugestão **Placar Um**.

### Filtro

Marque **Ativar filtragem** para disponibilizar o campo **Variável de filtragem**. Nessa lista, você pode selecionar uma variável permanente de usuário para utilizar no filtro do placar.

Se quiser comparar também seu valor, marque **Comparar o valor da variável de filtragem**. Você pode digitar um número no campo ou clicar no ícone **Escolha uma variável** ao lado dele para selecionar uma destas variáveis internas do quarto:

| Variável | Informação disponível |
| :--- | :--- |
| `@furni_count` | [Quantidade de mobis no quarto](/referencia/variaveis/wf_var_room/#variáveis-internas-do-quarto). |
| `@user_count` | [Quantidade de usuários no quarto](/referencia/variaveis/wf_var_room/#variáveis-internas-do-quarto). |
| `@wired_timer` | [Temporizador do quarto](/referencia/variaveis/wf_var_room/#temporizador-do-quarto). |
| `@teams` | [Informações dos times](/referencia/variaveis/wf_var_room/#informações-dos-times). |
| `@room_id` | [Identificador do quarto](/referencia/variaveis/wf_var_room/#identificador-do-quarto). |
| `@group_id` | [Identificador do grupo associado ao quarto](/referencia/variaveis/wf_var_room/#variáveis-internas-do-quarto). |
| `@current_time` | [Tempo atual](/referencia/variaveis/wf_var_room/#tempo-atual). |

### Localização do placar

Arraste o placar pelo quarto para escolher onde ele será exibido. Se preferir, você pode ajustar sua posição manualmente pelos campos:

* **Piso:** define a coordenada do piso associado ao placar.
* **Deslocamento:** o primeiro campo ajusta a posição horizontal, e o segundo ajusta a posição vertical.

Depois de organizar a posição e conferir as demais opções, salve as configurações para exibir o placar aos usuários do quarto.
