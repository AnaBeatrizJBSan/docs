O **Efeito: Bot dá item de mão**, faz com que o bot selecionado entregue ao usuário selecionado o item de mão definido nas configurações do Wired.

<Infobox />

## Configurações

**Nome do bot (Opcional)**: Ao marcar a opção “Dar item de mão usando um bot”, será exibido um campo para informar o nome do bot que entregará o item de mão.

Caso queira selecionar um bot específico sem precisar identificá-lo pelo nome, você pode ajustar essa opção nas [configurações Avançadas](#configurações-avançadas).

**Item de mão**
- Nenhum
- Leite
- Água
- Café
- Café descafeinado
- Café com leite
- Chá Árabe
- Arma
- Antídoto
- Arco

## Configurações avançadas

**Selecione o bot fonte:**
- Use o bot especificado pelo nome
- Usar usuários do seletor
- Usar usuários do sinal
- Usar usuário acionador

**Selecione usuários fonte**
- Use o usuário acionador
- Usar usuários do seletor
- Usar usuários do sinal
