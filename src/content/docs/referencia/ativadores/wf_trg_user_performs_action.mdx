O **Ativador: Habbo faz ação** é ativado sempre que um usuário do quarto faz a ação selecionada nas configurações desse wired.

<Infobox />

Sentar em uma cadeira, deitar em uma cama ou simplesmente dançar pode ativar esse wired. 

Por **não possuir** configurações avançadas, qualquer usuário do quarto consegue ativar esse wired quando feito a ação.

Na maioria dos cenários, considere utilizar wireds de **condições** para evitar o acionamento desnecessário. 

Bots podem ativar esse wired caso faça a ação selecionada, pois são considerados “usuários”.

## Configurações
Escolha uma das seguintes ações abaixo para acionar esse wired:
- Acenar
- Mandar um beijo
- Rir
- Curti!
- Acordar
- Inativo
- Sentar
- Levantar
- Deitar
- Sinais
- Dançar
- 67 (temporary)
