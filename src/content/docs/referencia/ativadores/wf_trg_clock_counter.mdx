Este wired é ativado quando um mobi do tipo **cronômetro**, previamente selecionado, atinge o tempo definido nas configurações adicionais.

<Infobox />

## Configurações
- **Passaram X minutos:** define a quantidade de minutos, de 0 a 99.
- **Passaram X segundos:** define a quantidade de segundos, de 0 a 60.

Ambas as configurações funcionam em conjunto. Por exemplo, se você definir 2 minutos e 5 segundos, o Wired será ativado quando um dos cronômetros selecionados atingir esse tempo.

## Configurações avançadas
Você pode escolher mais de um cronômetro usando as configurações avançadas:
- Use mobis escolhidos
- Usar mobis do seletor

## Dicas de uso
- Prefira usar o **Wired Cronômetro Pequeno**, além de não ocupar muito espaço, caso seu quarto tenha algo relacionado a um jogo Banzai ou Freeze, ele não afetará o funcionamento desses jogos.
