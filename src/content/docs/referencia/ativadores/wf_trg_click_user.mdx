Este Wired é ativado sempre que um Habbo clica em outro usuário dentro do quarto. Por **não possuir** configurações avançadas para selecionar usuários específicos, seu acionamento ocorre sempre que essa interação acontece, desde que não haja **wireds de condição** restringindo seu funcionamento.

<Infobox />

## Configurações

Este wired possui duas opções que permitem personalizar o comportamento do usuário que clicou: 

- **Não abrir o menu do avatar:** impede que o menu de interação do avatar seja exibido quando um Habbo clica em outro usuário.
- **Não gire:** impede que o Habbo que realizou o clique gire em direção ao usuário clicado.

<Aside type="caution" title="Comportamento padrão">
Por padrão, ao colocar este Wired no quarto, a opção **Não abrir o menu do avatar** já vem ativada. Isso significa que, ao clicar em outro Habbo, o menu de interação do avatar não será exibido.

Portanto, caso você perceba que o menu de um usuário não está abrindo ao clicar nele, verifique se essa opção está ativada nas configurações do Wired.
{/* E FUNCIONA MESMO! */}
</Aside>

## Dicas de uso
- Evite utilizar este wired sem **wireds de condições** específicos para controlar a ativação da pilha. Caso contrário, ele poderá prejudicar a experiência dos usuários, impedindo, por exemplo, que o menu de um Habbo seja exibido ao clicar nele, mesmo quando o clique é realizado pelo próprio usuário em si mesmo.
