# starlight-sidebar-label-sort

Plugin genérico para o Astro [Starlight](https://starlight.astro.build/) que ordena automaticamente os itens da barra lateral (sidebar) em ordem alfabética pelo `sidebar.label` (ou `title`), em vez do nome do arquivo / slug.

## Por que este plugin?

Por padrão, quando se utiliza `autogenerate: { directory: '...' }` no Starlight:
- As páginas são ordenadas internamente pelo nome do arquivo / slug (ex.: `wf_trg_walks_on_furni` fica na letra W, mesmo que seu título e rótulo no sidebar seja "Habbo anda no Mobi").
- A única forma nativa de alterar isso seria definindo `sidebar.order` manualmente em cada arquivo markdown/mdx da pasta.

Com este plugin:
1. Grupos autogerados são automaticamente ordenados em ordem alfabética utilizando `Intl.Collator` (suporte a acentuação e ordenação natural em português `pt-BR`).
2. Páginas de visão geral / introdução (`visao-geral`, `overview`, `index`) ficam automaticamente fixadas no topo da seção.
3. Se algum arquivo possuir `sidebar.order` explícito no frontmatter, a ordem configurada continua sendo respeitada com prioridade.
4. A paginação inferior (botões *Página anterior* / *Próxima página*) é recalculada automaticamente para acompanhar a nova ordem alfabética do sidebar.

## Instalação / Uso

### 1. No mesmo projeto ou copiando para outro

Copie a pasta `plugins/starlight-sidebar-label-sort` para a pasta `plugins/` do seu projeto.

Adicione ao seu `package.json`:

```json
"dependencies": {
  "starlight-sidebar-label-sort": "file:./plugins/starlight-sidebar-label-sort"
}
```

### 2. Configure em `astro.config.mjs`

```javascript
import { defineConfig } from 'astro/config';
import starlight from '@astrojs/starlight';
import starlightSidebarLabelSort from 'starlight-sidebar-label-sort';

export default defineConfig({
  integrations: [
    starlight({
      plugins: [
        starlightSidebarLabelSort({
          locale: 'pt-BR', // Padrão: 'pt-BR' ou o idioma da rota
          pinned: ['visao-geral', 'visão geral', 'overview', 'index'], // Fixados no topo
        }),
      ],
    }),
  ],
});
```

## Opções

| Opção | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `locale` | `string \| string[]` | `'pt-BR'` | Idioma para o `Intl.Collator`. Se não especificado, utiliza o idioma da rota ou `'pt-BR'`. |
| `collatorOptions` | `Intl.CollatorOptions` | `{ sensitivity: 'base', numeric: true }` | Opções passadas para o `Intl.Collator`. |
| `pinned` | `(string \| RegExp)[]` | `['visao-geral', 'visão geral', 'overview', 'index', 'introducao', 'introdução']` | Itens ou slugs que devem sempre ficar fixados no topo do grupo. |
| `pinnedBottom` | `(string \| RegExp)[]` | `[]` | Itens que devem sempre ficar fixados no final do grupo. |
| `onlyAutogenerated` | `boolean` | `true` | Se `true`, apenas ordena grupos autogerados (`autogenerate`), mantendo a ordem manual de links configurados no `astro.config.mjs`. |
| `externalLinksAtBottom` | `boolean` | `true` | Mantém links externos (`https://...`) ao final do grupo. |
| `syncPagination` | `boolean` | `true` | Recalcula a paginação (*Anterior* / *Próximo*) para corresponder à ordem alfabética da sidebar. |
| `respectOrder` | `boolean` | `true` | Respeita o campo `sidebar.order` definido no frontmatter, caso exista. |
